# Регулярные выражения

> 💡 **Руководство по обучению**: регулярные выражения выглядят как заклинания? На самом деле это просто мини-язык для «описания текстовых шаблонов». Эта глава поможет вам с нуля понять основную идею регулярных выражений и научиться с помощью нескольких ключевых символов решать 80% задач по поиску и проверке текста.

---

## 0. Зачем вам нужны регулярные выражения?

Представьте такие ситуации:
- Найти все IP-адреса в большом блоке логов
- Проверить, корректен ли формат e-mail, введённого пользователем
- Заменить в тексте все даты формата `2024/01/15` на `2024-01-15`
- Извлечь все ссылки из исходного кода веб-страницы

**Обычным поиском по строке?** Вам придётся написать кучу логики с `if-else`.
**Регулярным выражением?** Одна строка-шаблон решает всё.

## 2. Ключевые понятия: собираем как из кубиков

Суть регулярных выражений — собрать нужный вам шаблон из **трёх видов кубиков**:

### 2.1 Кубик первый: классы символов (какой символ сопоставлять)

| Синтаксис | Значение | Пример |
|---|---|---|
| `.` | Любой символ | `a.c` → abc, a1c, a c |
| `\d` | Цифра [0-9] | `\d\d` → 42, 99 |
| `\w` | Буква/цифра/подчёркивание | `\w+` → hello, user_1 |
| `\s` | Пробельный символ | сопоставляет пробел, Tab |
| `[abc]` | Любой из множества | `[aeiou]` → гласные буквы |
| `[^abc]` | Не входящий в множество | `[^0-9]` → нецифровые символы |

### 2.2 Кубик второй: квантификаторы (сколько раз сопоставлять)

| Синтаксис | Значение | Пример |
|---|---|---|
| `*` | 0 или более раз | `ab*` → a, ab, abbb |
| `+` | 1 или более раз | `ab+` → ab, abbb (не сопоставляет a) |
| `?` | 0 или 1 раз | `colou?r` → color, colour |
| `{3}` | Ровно 3 раза | `\d{3}` → 123 |
| `{2,4}` | От 2 до 4 раз | `\d{2,4}` → 12, 1234 |

### 2.3 Кубик третий: позиции и группировка

| Синтаксис | Значение | Пример |
|---|---|---|
| `^` | Начало строки | `^Hello` → строки, начинающиеся с Hello |
| `$` | Конец строки | `end$` → строки, заканчивающиеся на end |
| `\b` | Граница слова | `\bcat\b` → cat (не сопоставляет catch) |
| `(...)` | Захватывающая группа | `(\d+)-(\d+)` → захват по отдельности |
| `a\|b` | Или | `cat\|dog` → cat или dog |

## 3. Практика: распространённые шаблоны проверки

### 3.1 Проверка e-mail

```
[\w.+-]+@[\w-]+\.[\w.]+
```

Разбор:
- `[\w.+-]+` — часть с именем пользователя (буквы, цифры, точка, плюс, дефис)
- `@` — литеральный @
- `[\w-]+` — часть с доменом
- `\.` — экранированная точка
- `[\w.]+` — домен верхнего уровня

### 3.2 Проверка номера телефона (Китай)

```
1[3-9]\d{9}
```

Разбор:
- `1` — начинается с 1
- `[3-9]` — вторая цифра от 3 до 9
- `\d{9}` — далее следуют 9 цифр

### 3.3 Проверка надёжности пароля

```
^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$
```

Разбор:
- `(?=.*[a-z])` — хотя бы одна строчная буква (опережающая проверка)
- `(?=.*[A-Z])` — хотя бы одна заглавная буква
- `(?=.*\d)` — хотя бы одна цифра
- `.{8,}` — общая длина не менее 8 символов

## 4. Использование регулярных выражений в коде

### JavaScript

```javascript
const text = 'Контакты: 13812345678 или 15099887766'
const regex = /1[3-9]\d{9}/g
const phones = text.match(regex)
// ['13812345678', '15099887766']

// Замена
text.replace(/\d{4}(?=\d{4}$)/, '****')
// Скрываем четыре средние цифры номера телефона

// Проверка
/^[\w.+-]+@[\w-]+\.[\w.]+$/.test('user@example.com')
// true
```

### Python

```python
import re

text = 'Цена 99 юаней, скидка 20 юаней'
numbers = re.findall(r'\d+', text)
# ['99', '20']

# Замена
re.sub(r'\d+', 'X', text)
# 'Цена X юаней, скидка X юаней'

# Захват групп
match = re.search(r'(\d+)-(\d+)', '2024-01-15')
match.group(1)  # '2024'
match.group(2)  # '01'
```

## 5. Жадность vs ленивость: одно ключевое различие

```
Текст: <b>hello</b> and <b>world</b>
```

| Шаблон | Результат сопоставления | Пояснение |
|---|---|---|
| `<b>.*</b>` | `<b>hello</b> and <b>world</b>` | Жадный: сопоставляет как можно больше |
| `<b>.*?</b>` | `<b>hello</b>` | Ленивый: сопоставляет как можно меньше |

::: tip 💡 Запомните
По умолчанию режим жадный. Добавьте `?` после квантификатора, чтобы сделать его ленивым. В большинстве случаев вам нужен именно ленивый режим.
:::

## 6. Итог

::: tip 📚 Ключевые моменты
1. **Регулярное выражение = мини-язык описания текстовых шаблонов** для поиска, сопоставления и замены
2. **Три вида кубиков**: классы символов (что сопоставлять) + квантификаторы (сколько раз) + позиции/группировка
3. **\d \w \s** — три самых часто используемых класса символов, покрывают цифры, слова, пробелы
4. **Не нужно писать с нуля**: для распространённых сценариев есть готовые проверенные шаблоны, которые можно переиспользовать
5. **Жадность vs ленивость**: по умолчанию жадный (сопоставляет много), добавьте `?` для ленивого (сопоставляет мало)
:::
