# Нейронные сети и глубокое обучение

::: tip Предисловие
**Нейронные сети — это двигатель революции ИИ.** От понимания языка в ChatGPT до распознавания изображений в беспилотных автомобилях — за всем этим стоит работа нейронных сетей. Это не магия, а изящная математическая система, которая «обучается» отображению входа в выход на больших объёмах данных. Понимание её базовых принципов поможет вам лучше использовать и отлаживать ИИ-инструменты.
:::

## 1. От нейрона к сети

### Отдельный нейрон

Наименьшая единица нейронной сети — **нейрон** (Neuron). Он моделирует работу биологического нейрона: принимает несколько входных сигналов, вычисляет их взвешенную сумму и через функцию активации формирует выход.

```
вход x1 ──→ ×w1 ──┐
вход x2 ──→ ×w2 ──┼──→ Σ(взвешенная сумма) + b(смещение) ──→ f(функция активации) ──→ выход
вход x3 ──→ ×w3 ──┘
```

Математическая запись: **y = f(w₁x₁ + w₂x₂ + w₃x₃ + b)**

### Функция активации: зачем нужна нелинейность?

Без функции активации, сколько бы слоёв нейронов мы ни складывали, итог всё равно эквивалентен одному линейному преобразованию (умножению матриц). Функция активации вносит **нелинейность**, позволяя сети обучаться сложным закономерностям.

| Функция активации | Формула | Особенности | Типичное применение |
|---------|------|------|---------|
| ReLU | max(0, x) | простая и эффективная, быстрое обучение | выбор по умолчанию для скрытых слоёв |
| Sigmoid | 1/(1+e⁻ˣ) | выход 0~1 | выходной слой бинарной классификации |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | выход -1~1 | часто используется в RNN |
| Softmax | eˣᵢ/Σeˣⱼ | выход — распределение вероятностей | выходной слой многоклассовой классификации |

### От нейрона к сети

Если организовать несколько нейронов в **слой**, а несколько слоёв соединить последовательно, получится нейронная сеть:

```
входной слой     скрытый слой 1   скрытый слой 2   выходной слой
(признаки)       (низкоуровневые  (высокоуровневые (результат
                  признаки)        признаки)        предсказания)

 x1 ──→  [○ ○ ○ ○] ──→ [○ ○ ○] ──→  [○ ○]
 x2 ──→  [○ ○ ○ ○] ──→ [○ ○ ○] ──→  кошка/собака
 x3 ──→  [○ ○ ○ ○] ──→ [○ ○ ○]
```

| Концепция | Описание |
|------|------|
| Входной слой | принимает исходные данные (пиксели изображения, векторы текста и т. д.) |
| Скрытый слой | промежуточный слой обработки; чем больше слоёв, тем «глубже» сеть («глубокий» в глубоком обучении) |
| Выходной слой | формирует итоговое предсказание (вероятности классов, значения регрессии и т. д.) |
| Прямое распространение | процесс прохождения данных от входного слоя к выходному, слой за слоем |

::: tip Почему обучение называют «глубоким»?
В традиционном машинном обучении обычно всего 1–2 слоя. Когда число скрытых слоёв возрастает до десятков и даже сотен, обучение называют «глубоким». Более глубокая сеть способна обучаться более абстрактным признакам: первый слой учит границы, второй — текстуры, третий — части объектов, а ещё более глубокие слои улавливают, что «это кошка».
:::

## 2. Как сеть учится

«Обучение» нейронной сети по своей сути — это **задача оптимизации**: найти такой набор весов (w) и смещений (b), при котором предсказания сети максимально близки к истинным ответам.

### Три шага обучения

```
1. Прямое распространение: подаём данные, получаем предсказание
2. Вычисление потерь: функцией потерь измеряем расхождение предсказания с истинным значением
3. Обратное распространение: по потерям вычисляем градиент каждого веса, обновляем веса
   ↓
повторяем эти шаги, пока потери не станут достаточно малыми
```

### Функция потерь: измеряем, «насколько сильно ошиблись»

Функция потерь (Loss Function) количественно выражает расхождение между предсказанным и истинным значением. Цель обучения — минимизировать потери.

| Функция потерь | Краткое описание формулы | Применение |
|---------|---------|---------|
| MSE (среднеквадратичная ошибка) | среднее квадратов разностей предсказания и истины | задачи регрессии |
| Cross-Entropy (перекрёстная энтропия) | -Σ y·log(ŷ) | задачи классификации |
| Binary Cross-Entropy | бинарная версия перекрёстной энтропии | задачи бинарной классификации |

### Градиентный спуск: находим самую низкую точку

Представьте, что вы стоите на горе с завязанными глазами и должны спуститься в самую низкую точку. Всё, что вы можете, — **нащупать уклон под ногами и сделать шаг вниз по склону**. Это и есть градиентный спуск.

```
значение потерь
  ↑
  │    ╱╲
  │   ╱  ╲      ← текущая позиция
  │  ╱    ╲    ↙ спуск по направлению градиента
  │ ╱      ╲╱   ← локальный минимум
  │╱            ╲╱  ← глобальный минимум
  └──────────────→ значение веса
```

| Концепция | Описание |
|------|------|
| Градиент | частная производная функции потерь по каждому весу; указывает, «в каком направлении менять вес, чтобы уменьшить потери» |
| Скорость обучения | насколько большой шаг делается. Слишком большая — перепрыгнем минимум, слишком маленькая — сходимость будет слишком медленной |
| Размер батча | сколько примеров используется для вычисления градиента. Весь набор — слишком медленно, один пример — слишком «дёргано», мини-батч (mini-batch) — компромисс |

### Обратное распространение: триумф цепного правила

Обратное распространение (Backpropagation) — это эффективный алгоритм вычисления градиентов. Оно использует **цепное правило** из математического анализа: начиная с выходного слоя, слой за слоем вычисляет вклад каждого веса в потери.

```
прямое распространение: вход → скрытый слой 1 → скрытый слой 2 → выход → потери
обратное распространение: потери → выход → скрытый слой 2 → скрытый слой 1 → обновление всех весов
```

::: tip Интуитивное понимание обратного распространения
Представьте нейронную сеть как производственный конвейер. Продукт (предсказание) оказался бракованным (большие потери), и вам нужно с последней операции двигаться назад, проверяя, какой вклад каждая операция (каждый слой весов) внесла в итоговую проблему, и корректировать пропорционально вкладу. У кого вклад больше — корректируем сильнее, у кого меньше — слабее.
:::

## 3. Основные архитектуры сетей

Разные типы данных требуют разных архитектур сети. Правильный выбор архитектуры экономит вдвое усилий.

### 3.1 CNN (свёрточная нейронная сеть)

CNN — король обработки изображений. Основная идея: небольшое свёрточное ядро скользит по изображению, извлекая локальные признаки.

```
входное изображение → [свёртка→активация→пулинг] × N → полносвязный слой → выход
  28×28               извлечение границ/текстур/форм                результат классификации
```

| Особенность | Описание |
|------|------|
| Локальная связность | каждый нейрон видит лишь небольшой участок, а не всё изображение |
| Совместное использование параметров | одно свёрточное ядро переиспользуется по всему изображению, что резко сокращает число параметров |
| Инвариантность к сдвигу | кошка распознаётся как слева, так и справа на изображении |
| Иерархия признаков | поверхностные слои учат границы, глубокие — семантику |

Представительные модели: LeNet, AlexNet, VGG, ResNet, EfficientNet

### 3.2 RNN (рекуррентная нейронная сеть)

RNN создана специально для **последовательных данных**. Её скрытое состояние передаётся на следующий временной шаг, придавая сети способность «помнить».

```
шаг t1       шаг t2        шаг t3
 "я"   ──→   "люблю"  ──→  "кошек"
  ↓           ↓             ↓
 [h1]  ──→  [h2]    ──→   [h3] ──→ выход
  ↑           ↑             ↑
 скрытое состояние передаётся между шагами (память)
```

| Вариант | Решаемая проблема | Основной механизм |
|------|-----------|---------|
| Исходная RNN | базовое моделирование последовательностей | простая рекуррентная связь |
| LSTM | затухание градиента на длинных последовательностях | вентили забывания, входа и выхода |
| GRU | у LSTM слишком много параметров | упрощение до вентилей сброса и обновления |
| Двунаправленная RNN | способна видеть только прошлое | одновременная обработка слева направо и справа налево |

::: tip Вентильный механизм LSTM
Изящество LSTM — в трёх «вентилях»: **вентиль забывания** решает, какую старую память отбросить, **вентиль входа** — какую новую информацию сохранить, **вентиль выхода** — что выдать наружу. Это как при чтении книги: вы избирательно запоминаете важные сюжетные линии и забываете несущественные детали.
:::

### 3.3 Transformer: внимание — это всё, что нужно

В 2017 году в статье "Attention Is All You Need" компания Google представила Transformer, который полностью изменил область ИИ. Он заменил рекуррентную структуру **механизмом самовнимания** и стал основой больших моделей — GPT, BERT, Claude и других.

```
входная последовательность → эмбеддинг + позиционное кодирование → [многоголовое внимание → прямая сеть] × N → выход
                                                                          ↑
                                                          каждое слово «видит» все остальные слова
```

| Преимущество | Описание |
|------|------|
| Параллельные вычисления | в отличие от RNN, которой приходится обрабатывать пошагово, Transformer может обрабатывать всю последовательность параллельно |
| Дальние зависимости | прямая связь между любыми двумя позициями, без ограничения расстоянием |
| Масштабируемость | чем больше модель и данных, тем лучше результат (Scaling Law) |

**Интуиция самовнимания**: при чтении предложения «Котёнок сидит на коврике, потому что **он** устал» слову «он» нужно обратить внимание на «котёнка», чтобы понять смысл. Самовнимание учит модель такой связи — вычисляя «оценку релевантности» для каждой пары слов в последовательности.

## 4. Искусство обучения

Хорошей архитектуры недостаточно — в процессе обучения есть много «ловушек», которых нужно избегать.

### 4.1 Переобучение vs недообучение

| Проблема | Проявление | Причина | Решение |
|------|------|------|---------|
| Переобучение | хорошо на обучающей выборке, плохо на тестовой | модель слишком сложна, «зубрит ответы» вместо изучения закономерностей | регуляризация, Dropout, аугментация данных, ранняя остановка |
| Недообучение | плохо и на обучающей, и на тестовой выборке | модель слишком проста, не способна уловить закономерности | увеличить ёмкость модели, обучать дольше, лучшие признаки |

```
ошибка
  ↑
  │ ╲  ошибка обучения      ошибка теста  ╱
  │  ╲                                    ╱
  │   ╲─────────────────╱
  │  недообучение ← оптимум → переобучение
  └──────────────────────────→ сложность модели
```

### 4.2 Ключевые гиперпараметры

Гиперпараметры — это параметры, которые человек задаёт перед обучением (модель не учит их сама):

| Гиперпараметр | Назначение | Типичный диапазон | Рекомендации по настройке |
|--------|------|---------|---------|
| Скорость обучения | величина каждого шага обновления | 1e-5 ~ 1e-1 | важнейший гиперпараметр, обычно начинают с 1e-3 |
| Размер батча | сколько примеров используется за раз | 16 ~ 512 | чем больше, тем стабильнее обучение, но нужно больше видеопамяти |
| Число эпох (Epoch) | сколько раз проходим весь набор данных | 10 ~ 100+ | в сочетании с ранней остановкой: когда валидационная выборка перестаёт улучшаться, останавливаемся |
| Оптимизатор | стратегия обновления градиента | Adam, SGD | Adam — выбор по умолчанию, SGD+импульс подходит для тонкой настройки |

### 4.3 Приёмы регуляризации

Распространённые средства предотвращения переобучения:

| Приём | Принцип | Способ применения |
|------|------|---------|
| Dropout | при обучении случайно отключает часть нейронов | обычно p=0.1~0.5 |
| Weight decay (затухание весов) | добавляет в функцию потерь штраф за величину весов | L2-регуляризация, λ=1e-4 |
| Аугментация данных | случайные преобразования обучающих данных (отражение, обрезка, поворот) | обязательна для задач с изображениями |
| Ранняя остановка | прекращение обучения, когда потери на валидации перестают падать | patience=5~10 |
| Batch Normalization | нормализация распределения входа каждого слоя | ускоряет сходимость, даёт лёгкий регуляризирующий эффект |

::: tip Эмпирические правила обучения
1. Сначала прогоните весь процесс на маленьком наборе данных, чтобы убедиться в отсутствии багов в коде
2. Начинайте с тонкой настройки готовой предобученной модели, а не с обучения с нуля
3. Скорость обучения — гиперпараметр, на настройку которого стоит потратить больше всего времени
4. Если потери на обучении не снижаются, сначала проверьте данные и код, и только потом подозревайте модель
:::

## 5. История развития и передовые рубежи

Развитие нейронных сетей пережило несколько «зим» и «возрождений», и каждый прорыв был вызван ключевой технической инновацией.

| Эпоха | Веха | Ключевой прорыв |
|------|--------|---------|
| 1958 | Перцептрон (Perceptron) | первая модель нейронной сети, способная решать только линейные задачи |
| 1986 | Алгоритм обратного распространения | сделал возможным обучение многослойных сетей |
| 1998 | LeNet (CNN) | свёрточная сеть добилась большого успеха в распознавании рукописных цифр |
| 2012 | AlexNet | глубокая CNN разгромила традиционные методы на ImageNet, взрыв глубокого обучения |
| 2014 | GAN (генеративно-состязательная сеть) | две сети обучаются в состязании, способны генерировать реалистичные изображения |
| 2017 | Transformer | "Attention Is All You Need", механизм внимания заменил RNN |
| 2018 | BERT | парадигма «предобучение + тонкая настройка», всесторонний прорыв в NLP |
| 2020 | GPT-3 | 175 миллиардов параметров, продемонстрировал эмерджентные способности больших моделей |
| 2022 | ChatGPT | технология выравнивания RLHF, ИИ вошёл в поле зрения массового пользователя |
| 2023+ | Мультимодальные большие модели | GPT-4V, Claude и др., одновременно понимают текст и изображения |

### Текущие тенденции

| Направление | Описание |
|------|------|
| Большие модели (LLM) | число параметров от сотен миллионов до триллионов, возникают способности к рассуждению, программированию и т. д. |
| Мультимодальность | одна модель обрабатывает текст, изображения, аудио, видео |
| Эффективная тонкая настройка | технологии вроде LoRA, QLoRA позволяют дообучать большие модели даже обычным разработчикам |
| AI Agent | большая модель использует инструменты, планирует задачи и автономно достигает сложных целей |
| Дистилляция малых моделей | обучение малой модели на знаниях большой для развёртывания на конечных устройствах |

::: tip Что это значит для разработчиков
Вам не нужно обучать нейронную сеть с нуля. Современная разработка ИИ — это больше про **вызов API** (например, OpenAI, Claude API) или **тонкую настройку предобученных моделей** (например, через Hugging Face). Но понимание базовых принципов поможет вам лучше выбирать модель, проектировать prompt и диагностировать проблемы.
:::

| Нейрон | взвешенная сумма + функция активации, наименьшая вычислительная единица сети |
| Прямое распространение | данные текут от входного слоя к выходному, формируя предсказание |
| Обратное распространение | отталкиваясь от потерь, послойно вычисляем градиенты и обновляем веса |
| CNN | свёрточные ядра извлекают локальные признаки, первый выбор для обработки изображений |
| RNN/LSTM | рекуррентные связи сохраняют память, обработка последовательных данных |
| Transformer | самовнимание с параллельной обработкой, базовая архитектура больших моделей |
| Переобучение | модель «зубрит ответы», предотвращается регуляризацией, Dropout и др. |
| Перенос обучения | стоя на плечах гигантов, решаем новые задачи тонкой настройкой предобученной модели |
